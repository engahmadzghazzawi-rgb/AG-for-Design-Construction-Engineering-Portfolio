AG for Design & Construction — Website package

Files:
- index.html: responsive Arabic/English portfolio website.

How to preview:
1. Open index.html in Chrome, Edge, Firefox, or another browser.
2. Internet access is needed for the remote portfolio photos.

How to publish for free with GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example: ag-design-construction
3. Upload index.html to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for the published URL shown in the Pages settings.

The free website URL will be a GitHub Pages subdomain, not a custom .com domain.
Before publishing, verify contact details and replace the illustrative stock photos/captions in the Portfolio section with actual projects. The form opens WhatsApp with a prefilled message; it does not store submissions on a server.
